# Replika Facebook prijavne in registracijske strani

Ta projekt je **replika prijavne strani in strani za registracijo Facebooka**, narejena za šolski projekt.  
Cilj je bil čim bolj natančno posnemati izgled in postavitev originalnih strani ter pri tem vaditi HTML, CSS in JavaScript.

## 🧱 Uporabljene tehnologije

V projektu sem uporabil:

- **HTML** za ogrodje strani (struktura elementov)
- **CSS** za urejanje izgleda (barve, postavitev, razmiki, tipografija)
- **JavaScript** za osnovne funkcionalnosti (npr. preverjanje vnosov, interakcije na obrazcih)

## 📂 Struktura projekta

Glavne datoteke v repozitoriju:

- `index.html` – prijavna stran (login stran 1)
- `login.html` – druga prijavna stran (prijava 2)
- `signup.html` – stran za registracijo novega računa
- `css/` – mapa s CSS datotekami za stiliranje
- `js/` – mapa z JavaScript datotekami za funkcionalnost
- `image/` – slike, uporabljene v projektu
- `LICENSE` – licenca projekta
- `README.md` – ta opis projekta

## 🚀 Kako odpreti projekt

1. Repozitorij preneseš ali kloniraš:
   ```bash
   git clone https://github.com/leonilc07/Obrazec2.git
   ```
2. Odpreš eno od HTML datotek v brskalniku:
   - `index.html` za prvo prijavno stran,
   - `login.html` za drugo prijavno stran,
   - `signup.html` za stran za registracijo.

Ni potrebna dodatna namestitev – dovolj je sodoben spletni brskalnik.

## ✅ Namen projekta

- vaja postavitve kompleksnejše strani z obrazci,
- posnemanje resnične znane spletne strani (Facebook),
- izboljšanje znanja **HTML**, **CSS** in **JavaScripta**,
- priprava projekta, ki ga lahko pokažem kot del svojega portfelja.
